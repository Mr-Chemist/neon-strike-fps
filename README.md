# Neon Strike FPS (Android Kotlin)

بازی شوتر اول شخص سه‌بعدی (First-Person Shooter) برای اندروید، نوشته‌شده ۱۰۰٪ با **Kotlin** بدون وابستگی به فایل‌های گرافیکی یا صوتی خارجی و مجهز به **GitHub Actions** برای ساخت خودکار فایل `APK`.

## ویژگی‌ها
- **موتور سه‌بعدی DDA Raycasting**: رندر ۶۰ فریم‌برثانیه با تکسچرهای رویه‌ای (Procedural Textures)، مه‌آلودگی فاصله، سایه‌زنی جهت‌دار و Z-Buffer برای نمایش دقیق دشمنان و آیتم‌ها پشت دیوار.
- **۳ سلاح متفاوت**: تپانچه تاکتیکی (Pistol)، شاتگان رزمی (Shotgun با پخش ساچمه) و تفنگ پالس رگباری (Pulse Rifle) با انیمیشن لگد، تعویض خشاب و جرقه شلیک.
- **۳ مرحله تاکتیکی و ۳ نوع دشمن با هوش مصنوعی**: پهپاد شناسایی (Drone)، سرباز زره‌پوش (Trooper) و ربات سنگین (Heavy Mech) با تشخیص خط دید، تعقیب، شلیک و نوار سلامت.
- **صداسازی رویه‌ای (Procedural Audio)**: تولید تمام افکت‌های صوتی شلیک، ریلود، برخورد و آیتم‌ها با `AudioTrack` در کاتلین.
- **کنترلر چندلمسی موبایل**: جوی‌استیک حرکت در سمت چپ، چرخش دوربین ۳۶۰ درجه در سمت راست، دکمه‌های شلیک، ریلود، تعویض سلاح و رادار زنده (Minimap).

## دریافت خروجی APK با GitHub Actions
1. فایل‌های داخل این پوشه را در یک مخزن جدید (Repository) در GitHub آپلود یا Push کنید.
2. وارد تب **Actions** در مخزن گیت‌هاب خود شوید.
3. ورک‌فلو **Build Android FPS APK** به‌صورت خودکار اجرا می‌شود (یا می‌توانید با دکمه `Run workflow` دستی اجرا کنید).
4. پس از اتمام بیلد، از بخش **Artifacts** فایل `NeonStrikeFPS-APK` را دانلود کرده و روی گوشی اندروید نصب کنید.
5. همچنین در صورت Push کردن تگ نسخه (مثلاً `v1.0.0`)، فایل APK به‌طور خودکار در بخش **Releases** منتشر می‌شود.
